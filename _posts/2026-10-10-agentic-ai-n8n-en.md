A chatbot answers the questions you ask. An AI agent does more: it performs tasks. With n8n you can build agents that actually do work for you — drafting quotes, answering emails, checking invoices.

In this article I explain the difference and how to build such an agent yourself.

## The difference between a chatbot and an AI agent

A chatbot reacts: you ask a question, it answers. An agent acts: it follows a step-by-step plan, uses tools itself and delivers a finished result.

Example: a customer sends a quote request. A chatbot summarises the question. An AI agent handles it entirely — pulling the data from your CRM, calculating the price from your rates, drafting the quote and sending it to you for approval by email.

## How do you build an agent in n8n?

Since its AI update, n8n has nodes that let you set up an agent without programming. The core consists of three parts:

- AI Agent node: the brain that decides what needs to happen
- Tools: existing n8n workflows the agent can use
- Memory: the agent remembers previous steps and context

The agent gets a system prompt in which you describe what it may do and which tools it uses. After that you can let it loose on real requests.

## Practical example: your own quote workflow

Say you already use n8n to forward contact forms. Now you expand it: the AI agent reads every request, follows up on missing details and calls a workflow that generates the quote.

The beauty is that every tool is a workflow you may already know. You build it step by step, and the agent decides when to use which step.

## What does it deliver?

- Less manual work on recurring tasks
- Faster responses to requests
- Employees do reviews instead of typing
